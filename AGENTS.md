# AGENTS.md

The guidance for coding agents in this repository is in [CLAUDE.md](CLAUDE.md). It applies to every agent, not only Claude Code: commands, architecture, testing rules and conventions. [CONTRIBUTING.md](CONTRIBUTING.md) covers scope and pull requests.

Two rules from it that apply to every commit and pull request:

- No AI session links or attribution: no `https://claude.ai/code/session_...` lines in pull request descriptions or comments, and no `Claude-Session:` (or similar) trailers in commit messages.
- Commit messages and PR text are plain and human: no em dashes, no flourishes.
